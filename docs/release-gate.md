# Release gate (plan phase 8)

This gate applies to publishing a release on PyPI. Nothing is frozen before
that (ADR-0010); freezing the public surface is a step of the first release,
not a constraint on work before it.

A release may drop the adapters' `experimental` label only when **every**
required check below passes on the release commit. Quarantine cannot satisfy a
required check: `release_gate` tests are refused by `tests/conftest.py` if they
are listed in `tests/quarantine.txt`.

| # | Required check | How |
| --- | --- | --- |
| G1 | Lint (flake8 fatal subset, `ty`) and the engine-free suite from the installed wheel on CPython 3.11 (locked) and 3.13 | xcookie-generated `.github/workflows/tests.yml`; locally `dev/ci/engine_free.sh` |
| G2 | Inspect native acceptance and conformance at the verified pin | `dev/ci/native_inspect.sh` (xcookie source check `native-inspect`, `checks.yml`) |
| G3 | OLMo native acceptance and conformance in the locked isolated checkout | `dev/ci/native_olmo.sh` (`native-olmo`, `checks.yml`) |
| G4 | HELM adapter native acceptance and conformance at the verified pin (MAGNET compatibility when reachable) | `dev/ci/native_helm.sh` (`native-helm`, `checks.yml`) |
| G5 | Regression fixtures match the current schema/normalization (regenerated and reviewed in the change that altered them); unknown future schema versions are rejected | `release_gate` tests: `test_schema_compat.py`, `test_native_fixture_regression.py` |
| G9 | At release time only: record the surface being frozen in a new ADR superseding ADR-0010 | maintainer decision |
| G10 | At release time only: the supported endpoint and sandbox configurations pass on the release candidate. Local OpenAI-compatible endpoint: Inspect `openai` provider (primary and auxiliary-role overrides) and OLMo LiteLLM/OpenAI Agents. Inspect Docker sandbox (isolation and cleanup). Real infer-stack leases (null serving backend) from MAGNET. | `external`/`docker_sandbox` tests in the Inspect `openai` variant and Docker-enabled environments; MAGNET's integration job. Scope revision R3. |
| G6 | Clean-environment walkthrough of generation and agentic examples | `dev/walkthrough.sh` |
| G7 | Sdist/wheel build whose only runtime dependency is `kwconf`, including `py.typed` and excluding tests | `uv build` and inspect the wheel |
| G8 | G1–G4 green on hosted CI (`tests.yml` and `checks.yml`, generated by xcookie from `[tool.xcookie]`) for the release commit | GitHub Actions |

Never in routine CI: tests marked `paid`, `gpu`, `external`, or
`docker_sandbox`. `paid` and `gpu` tests are never required. The `external`
(local endpoint) and `docker_sandbox` tests of the supported configurations are
required at release time through G10. A network error in an `external` test is reported as
`external-unavailable` at most once per session. It never applies to
`release_gate` tests, and a second failure is a real failure. Dependency
installation in the CI scripts is retried at most three times with backoff.
